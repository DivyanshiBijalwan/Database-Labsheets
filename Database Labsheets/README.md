# MCA105P – Database Labsheets Solutions

Complete solutions for Labsheets 6–10, organized by lab sheet and question number.

## Contents
- Labsheet 6: MySQL stored procedures and functions (20 questions)
- Labsheet 7: MySQL cursors (10) and triggers (10)
- Labsheet 8: MySQL functions and stored procedures (10)
- Labsheet 9: MongoDB + Flask student record management (12 questions)
- Labsheet 10: MongoDB + Flask hospital medicine management (13 questions)

## Important
- MySQL solutions target MySQL 8.0+.
- MongoDB solutions target MongoDB 6+ and PyMongo 4+.
- Run each lab's `setup.sql` before its SQL question files.
- MongoDB web applications are complete runnable projects in each lab folder; the `Questions/` subfolder contains question-wise practical examples.
- The labsheet 8 question sheet does not provide patient heights. The BMI report therefore uses an explicitly labeled sample height of 1.65 m; replace this with actual heights if supplied.
- Labsheet 7 Question 10 uses a custom BEFORE INSERT validation rule because the question asks for a trigger of the student's choice.
