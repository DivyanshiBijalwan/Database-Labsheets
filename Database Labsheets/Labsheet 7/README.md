# Labsheet 7 – Cursors & Triggers

Database: `Hospital_Cursor_Trigger_Lab` (MySQL 8.0+).

Run `setup.sql` first. Each Q file is independent by question number. Cursor procedures are named `cursor_q01` ... `cursor_q10`; triggers are named `trg_q01` ... `trg_q10`. Some trigger questions use the same audit tables, so run only the specific trigger file you are testing, or drop the existing trigger of that name before recreating it.
