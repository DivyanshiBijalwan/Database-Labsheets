# Labsheet 6 – Stored Procedures & Functions

Database: `CollegeDB` (MySQL 8.0+)

## Run
1. Open MySQL Workbench or MySQL Command Line Client.
2. Run `setup.sql` once.
3. Run the required `Q01.sql` ... `Q20.sql` files. Each file contains the solution and its test call.
4. Run routine scripts in separate executions if your SQL editor does not support `DELIMITER`.

The supplied practical sheet defines the pass threshold as 50 and grade bands A: 90+, B: 75–89, C: 60–74, D: below 60.
